# Plex Repairman

[Plex Repairman](https://github.com/chrisstoll1/plex-repair-discord-bot) is a Discord assistant for diagnosing and repairing Plex, Sonarr and Radarr media issues, with optional Seerr requests. Repairs follow configurable confirmation and Discord role policies.

Requires a Discord bot and OpenAI Codex authentication. First-time administrator setup requires the one-time token in /config/portal-setup-token. See the [setup and backup instructions](https://github.com/chrisstoll1/plex-repair-discord-bot#first-time-setup).
